🎛️ 關於我們

DJ 器材預購與入門學習平台 - 為 DJ 愛好者打造的一站式解決方案

系統目的與發想

系統目的

透過 FastAPI 構建高效能、模組化的整合平台，為 DJ 愛好者提供器材租售、課程報名與賽事資訊的一站式解決方案。

使用者痛點分析

📍 資訊較為破碎
當前 DJ 器材、課程與賽事資訊散落在不同的社群平台、網站、電商，使用者需耗費大量時間搜尋與交叉比對。
💼 管理成本高昂
主辦單位與廠商仍多透過人工表單處理報名與訂單，易發生資料錯誤或同步延遲。

使用情境與需求

👥 一般使用者

情境

尋找特定型號的 DJ 盤或音響設備，並同時關注近期的 DJ 競賽與教學課程。

需求

需要清晰的商品分類目錄、直覺的購物流程、快速的賽事報名機制，且能會員資料自動帶入功能，以節省重複輸入時間。

👨‍💼 管理員

情境

需要頻繁更新庫存商品資訊、發布最新比賽時程與課程詳情。

需求

一個易於操作的後台，能統一管理商品（新增/修改/刪除）、監控訂單狀況，並能一鍵匯出課程與賽事的報名者名單。

主要功能規劃

🛍️ 商品導覽與銷售

器材分類索引（DJ盤、音響、線材）、商品詳細頁、購物車及響應式結帳流程

👤 會員管理

註冊、登入系統，整合會員資料至購物、課程與比賽報名表單

📚 課程與賽事報名

包含自動化的篩選排序（按時間/難度）、報名截止自動失效

💬 意見反饋與合作

獨立的聯絡表單，區分一般客戶反饋與廠商贊助申請

⚙️ 後台管理系統

商品庫存與規格管理、賽事/課程內容維護、即時報名者清單查看

頁面規劃

📑 頁面主要架構

將頁面分為「公開瀏覽層」、「交易/報名層」與「管理控制層」：

  • 公開瀏覽層： 首頁、器材搜尋與詳情、課程介紹、比賽資訊、聯絡我們
  • 交易/報名層： 會員註冊/登入、購物車、結帳頁面（採用RWD）、個人報名紀錄
  • 管理控制層： /admin 管理儀表板（含 CRUD 控制台與報名者名單匯出）

🎨 頁面規劃特點

頁面分類 關鍵頁面 資訊規劃邏輯
導覽與展示 課程/比賽詳情頁 採用「資訊區塊化」設計，上方為重點導覽，下方整合互動表單，減少頁面切換
互動結帳 /checkout (RWD) 電腦版：雙欄佈局（左：訂單與總金額/右：個人資料）。手機版：單欄流式佈局，確保重要按鈕位於拇指操作熱區
管理後台 /admin 採用「列表檢視 + Modal 彈出式編輯」，管理員可於同一頁面切換檢視商品庫存與報名名單，無需頻繁導航

🔄 頁面互動流程與例外處理

報名截止邏輯： 當系統偵測到比賽日期超過 contest.end_date 時，前端將強制移除「立即報名」按鈕，並顯示「報名已截止」字樣，避免無效請求進入後端。
庫存與名額檢查： 在結帳流程的最後階段，系統會執行最後一次庫存確認；若名額已滿，頁面將轉向「錯誤通知頁（409 Conflict）」，並引導使用者返回列表或聯絡客服。
會員狀態橋接： 未登入狀態下嘗試報名或結帳時，系統將透過 Redirect 機制導向 /login，並於登入成功後，將使用者回傳至原目標頁面（Return URL），提升操作流暢度。

🔄 架構設計原理

分層架構

Routes 層 → Services 層 → Models 層

  • Routes：處理 HTTP 請求，驗證用戶輸入，調用業務邏輯層
  • Services：包含核心業務邏輯，與數據庫交互，返回結果
  • Models：定義數據結構，映射數據庫表

核心設計模式

  • ✅ MVC 分離 - Models（數據）、Views（路由），Controllers（Services 業務邏輯）
  • ✅ 依賴注入 - 使用 FastAPI 的 Depends 機制注入數據庫連接和用戶信息
  • ✅ Pydantic 驗證 - 在 Schemas 層進行數據驗證，確保數據完整性
  • ✅ RESTful API - 遵循 REST 原則，使用標準 HTTP 方法和狀態碼
  • ✅ 環境配置隔離 - 通過 config.py 管理環境變數，支持本地/生產環境切換

📋 程式架構 - API 路由詳解

💡 提示：本平台採用 RESTful 設計模式，支援多種頁面操作。點擊下方分類查看詳細的 API 路由說明。
🔐 認證路由 (Authentication)
方法 路由 說明
GET /register 顯示註冊頁面；若已登入則直接導向目標頁
POST /register 建立新帳號（帳號、Email、密碼、姓名、電話、地址），成功後自動登入並設定 cookie 導向首頁；失敗則顯示錯誤訊息
GET /login 顯示登入頁面；若已登入則直接導向目標頁（?next= 參數）
POST /login 驗證帳號密碼，成功後設定 cookie（session_id，7天有效）並導向目標頁；失敗則顯示錯誤訊息
GET /logout 清除 session_id cookie，導向首頁
🛍️ 商品瀏覽 (Product Browsing)
方法 路由 說明
GET /category 商品分類頁，可依商品類型、品牌、價格區間與頁數篩選商品
GET /detail 商品詳情頁，依 instrument 與 id 顯示指定商品內容與預購方案
GET /search 搜尋頁，可依關鍵字、商品類型、品牌、價格區間搜尋商品
📚 課程與賽事 (Courses & Contests)
方法 路由 說明
GET /course 列出所有上架課程，每頁 12 筆，可用 ?sort=difficulty 依難度排序，預設依建立時間倒序
GET /course/detail?id={id} 顯示單一課程詳細頁（課程介紹、大綱、報名表單），找不到回傳 404
POST /course/register 送出課程報名（姓名、Email、電話、備註），成功後導回詳細頁並顯示報名編號；失敗則顯示錯誤訊息
GET /contest 列出所有尚未結束的上架比賽（過期活動自動過濾），每頁 12 筆，依活動日期升序排列，並標記每場比賽是否可報名
GET /contest/detail?id={id} 顯示單一比賽詳細頁（地點、獎金、截止日、報名表單），並判斷是否已截止/額滿
POST /contest/register 送出比賽報名（姓名、Email、電話、DJ 藝名、備註），成功後導回詳細頁並顯示報名編號；失敗則顯示錯誤訊息
🛒 購物車 (Shopping Cart)
方法 路由 說明
GET /cart 顯示購物車頁面，列出目前所有商品與小計；未登入則導向登入頁
POST /cart/add 將商品加入購物車（支援 JSON 和 Form 兩種格式）；未登入回傳 401 或導向登入頁
POST /cart/update/{item_id} 更新購物車內指定商品的數量
POST /cart/remove/{item_id} 從購物車移除指定商品
POST /cart/clear 清空整個購物車
GET /cart/count 回傳購物車商品總件數（JSON，供前端 navbar 顯示數量用）；未登入回傳 0
💳 結帳 (Checkout)
方法 路由 說明
GET /checkout 顯示結帳頁面，帶入購物車內容；未登入導向登入頁，購物車為空則導回 /cart
POST /checkout 送出訂單（填寫姓名、Email、電話、地址、備註），成功後建立訂單並導向 /order-success?order_id=...；失敗則顯示錯誤訊息
⚙️ 管理後台 (Admin Panel)
方法 路由 說明
GET /admin/products 列出指定類型的商品（ddj、audio、wire、music，透過 query param ?instrument= 篩選）
POST /admin/products/create 新增一筆商品
POST /admin/products/{instrument}/{product_id}/edit 編輯指定商品內容
POST /admin/products/{instrument}/{product_id}/delete 刪除指定商品
GET /admin/orders 列出所有訂單（依建立時間倒序）
GET /admin/orders/{order_id} 查看單筆訂單詳細內容
POST /admin/orders/{order_id}/status 更新訂單狀態（例如：待處理 → 已出貨）
GET /admin/courses 列出所有課程
POST /admin/courses/{course_id}/edit 編輯課程內容（標題、難度、時數、講師、價格等）
GET /admin/courses/{course_id}/registrations 查看某課程的報名名單
GET /admin/courses/{course_id}/registrations/export 匯出課程報名名單為 CSV 檔
GET /admin/contests 列出所有比賽
POST /admin/contests/{contest_id}/edit 編輯比賽內容（標題、地點、獎金、日期等）
GET /admin/contests/{contest_id}/registrations 查看某比賽的報名名單
GET /admin/contests/{contest_id}/registrations/export 匯出比賽報名名單為 CSV 檔
📧 聯絡我們 (Contact)
方法 路由 說明
GET /contact 顯示聯絡我們頁面，包含聯絡資訊與表單
POST /contact/submit 送出聯絡表單，儲存使用者意見回饋或廠商合作訊息
